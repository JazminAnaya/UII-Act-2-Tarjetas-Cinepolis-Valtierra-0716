A new Flutter project.
##Promt de IA gemini
Lenguaje Flutter dart, nivel principiante, No uses codigo obsoleto para Dartpad. 
-Con el ejemplo de la imagen Dame un codigo completo para la empresa "Cinepolis Valtierra" con colores azules y blancos.
-En el body, con el subtitulo "Peliculas" crea  5 Tarjetas en una columna, la tarjeta debe tener una imagen desde la web a la izquierda (Yo cambiare las imagenes despues).
-Al lado derecho de la imagen: pon el nombre de una pelicula (Ejemplo "Avengers"), Director de la pelicula, clasificacion de la pelicula y calificacon de la pelicula en forma de lista pero sin puntos. 
-Deben de ser 5 peliculas diferentes.
